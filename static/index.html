Intern Problem Statement Spec • Architecture

The Core Objective: Build an Autonomous AI Task Worker capable of reading unstructured business documents (invoices, receipts, PDF/images), planning steps through a reasoning-action loop, interacting with web portals via browser automation, and validating task completion against storage audits.

“Find the latest invoice from Company X, extract the amount and due date, enter it into our internal system, and tell me once it is done.”
Directive → Understand (Hybrid RAG) → Plan (ReAct) → Execute (Playwright) → Observe → Adapt → Verify (Database Audit) → Complete

Evaluation Criteria Implemented:

  • Autonomy: LLM reasons over DOM accessibility snapshots without hardcoded scripts.
  • Execution: Real browser interaction handling inputs and form submissions.
  • Multimodal RAG: Ingestion of PDF & image invoices with hybrid BM25 + dense semantic retrieval.
  • Reliability: Retry backoffs, duplicate action mitigation, fallback selectors.
  • Human-in-the-Loop (HITL): Explicit privilege gate preventing unauthorized commits.
  • Outcome Verification: Independent validation against backend database.
